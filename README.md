## How to Publish (Free Options)

### Option 1: Netlify (EASIEST - Recommended)
1. Go to https://netlify.com and sign up free
2. Click "Add new site" > "Deploy manually"
3. Drag and drop this entire folder onto the page
4. Your site goes live instantly with a link like: https://nonlo.netlify.app
5. You can set a custom domain later

### Option 2: GitHub Pages (Free)
1. Go to https://github.com and create a free account
2. Create a new repository called "nonlo-website"
3. Upload both HTML files
4. Go to Settings > Pages > Deploy from main branch
5. Site goes live at: https://yourusername.github.io/nonlo-website

### Option 3: Vercel (Free)
1. Go to https://vercel.com
2. Sign up and click "Add New Project"
3. Drag and drop this folder
4. Live in 30 seconds
